<Layer kind="intuizione">

<div data-note-id="grafo-maglie-tagli-intuizione-1">

To write Kirchhoff's laws it does not matter whether a branch is a resistor or a source: only where it starts and where it ends matters. The graph is the "skeleton" of the circuit, the map of connections on which all topological equations rest.

</div>

</Layer>

<Layer kind="formalismo">

<div data-note-id="grafo-maglie-tagli-teoria-1">

A **directed graph** is a set of $n$ nodes and $b$ branches, each with a direction. The graph of a circuit is obtained by ignoring the nature of the components: each one-port is a branch, its terminals are nodes. It is assumed to be _connected_ (every node can be reached from every other), otherwise the separate parts are studied.

</div>

<div data-note-id="grafo-maglie-tagli-teoria-2">

A **loop** is a set of branches forming a closed path that passes only once through each node. A **cut set** is a minimal set of branches whose removal disconnects the graph. The branches meeting at a node form a cut set (the "node cut set").

</div>

<div data-note-id="grafo-maglie-tagli-teoria-3">

The branch directions coincide with the reference directions of the currents (and of the voltages, with the passive sign convention). For each loop a direction of traversal is fixed; for each cut set a direction is fixed (from the node set $\mathcal N_1$ to $\mathcal N_2$).

</div>

<Layer kind="esempio">

<div class="worked" data-note-id="grafo-maglie-tagli-esempio-1">

### Counting on the complete 4-node graph

In the graph of the figure (4 nodes, 6 branches): how many 3-branch loops are there? How many "node" cut sets?

**Solution.**

1. Every triple of nodes forms a triangle: $\binom{4}{3}=4$ loops of 3 branches.
2. One node cut set per node: 4 (but they are dependent: $n-1=3$ are enough).

</div>

</Layer>

<Layer kind="errori">

<div data-note-id="grafo-maglie-tagli-errore-1">

- **Wrong:** Calling a loop a set of branches that "closes" by passing twice through a node.
- **Right:** In the definition of loop every node is touched only once (otherwise it is a union of loops).

</div>
