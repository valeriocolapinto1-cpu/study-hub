<Layer kind="intuizione">

<div data-note-id="grafo-maglie-tagli-intuizione-1">

To write Kirchhoff's laws it does not matter whether a branch is a resistor or a source: only where it starts and where it ends matters. The graph is the "skeleton" of the circuit, the map of connections on which all topological equations rest.

</div>

<div data-note-id="grafo-maglie-tagli-intuizione-2">

The same graph can describe very different circuits: a resistor bridge and a bridge with capacitors and sources share the same skeleton, hence the same Kirchhoff equations. From one circuit to the other only the constitutive relations change. Separating topology from components is the step that makes analysis systematic.

</div>

</Layer>

<Layer kind="formalismo">

<div data-note-id="grafo-maglie-tagli-teoria-1">

A **directed graph** is a set of $n$ nodes and $b$ branches, each with a direction. The graph of a circuit is obtained by ignoring the nature of the components: each one-port is a branch, its terminals are nodes. It is assumed to be _connected_ (every node can be reached from every other), otherwise the separate parts are studied.

</div>

<div data-note-id="grafo-maglie-tagli-teoria-2">

A **loop** is a set of branches forming a closed path that passes only once through each node. A **cut set** is a minimal set of branches whose removal disconnects the graph. The branches meeting at a node form a cut set (the "node cut set").

</div>

<div data-note-id="grafo-maglie-tagli-teoria-3">

The branch directions coincide with the reference directions of the currents (and of the voltages, with the passive sign convention). For each loop a direction of traversal is fixed; for each cut set a direction is fixed (from the node set $\mathcal N_1$ to $\mathcal N_2$).

</div>

<div data-note-id="grafo-maglie-tagli-teoria-4">

**Planar graphs and meshes.** A graph is _planar_ if it can be drawn in the plane with no crossing branches. In that case the "windows" of the drawing, called _meshes_ or elementary loops, are $b-n+1$ (from Euler's formula) and form a set of independent loops: this is the most convenient choice for mesh analysis on hand-drawn circuits. For non-planar graphs the fundamental loops of a tree are used.

</div>

<div data-note-id="grafo-maglie-tagli-teoria-5">

**Cut set and closed surface.** Every cut set corresponds to a closed surface splitting the nodes into two groups $\mathcal N_1$ and $\mathcal N_2$: the branches of the cut set are those crossing it. The "node" cut set is the case where $\mathcal N_1$ contains a single node. With $n$ nodes there are $2^{n-1}-1$ ways to split them into two non-empty groups; a split gives a (minimal) cut set only if both groups remain connected.

</div>

<Layer kind="esempio">

<div class="worked" data-note-id="grafo-maglie-tagli-esempio-1">

### Counting on the complete 4-node graph

In the graph of the figure (4 nodes, 6 branches): how many 3-branch loops are there? How many "node" cut sets?

**Solution.**

1. Every triple of nodes forms a triangle: $\binom{4}{3}=4$ loops of 3 branches.
2. One node cut set per node: 4 (but they are dependent: $n-1=3$ are enough).

</div>

<div class="worked" data-note-id="grafo-maglie-tagli-esempio-2">

### All cut sets of the complete graph on 4 nodes

In the complete graph with nodes $0,1,2,3$ ($b=6$) list the cut sets and count how many are independent.

**Solution.**

1. Splits of the nodes into two groups: $2^{4-1}-1=7$.
2. $4$ splits isolate one node: cut sets of $3$ branches. The other $3$ separate two pairs, e.g. $\{0,1\}|\{2,3\}$: branches $0$-$2$, $0$-$3$, $1$-$2$, $1$-$3$, i.e. $4$ branches.
3. In the complete graph every group is connected, so all $7$ splits are cut sets; the independent KCLs remain $n-1=3$.

</div>

<Layer kind="errori">

<div data-note-id="grafo-maglie-tagli-errore-1">

- **Wrong:** Calling a loop a set of branches that "closes" by passing twice through a node.
- **Right:** In the definition of loop every node is touched only once (otherwise it is a union of loops).

</div>

<div data-note-id="grafo-maglie-tagli-errore-2">

- **Wrong:** Counting as distinct nodes two points joined by an ideal conductor.
- **Right:** An ideal conductor is not a branch: its ends are the same node. Before counting $n$ and $b$ it pays to redraw the circuit merging the nodes.

</div>

<div data-note-id="grafo-maglie-tagli-errore-3">

- **Wrong:** Thinking that a cut set must isolate a single node.
- **Right:** A cut set separates any two groups of nodes; the node cut set is only a special case (in the complete graph on 4 nodes there are 3 cut sets separating two pairs).

</div>
