<Layer kind="intuizione">

<div data-note-id="serie-parallelo-partitori-intuizione-1">

In series the current is forced through every resistor, so the "obstacles" add up; in parallel it has several paths, so the "ease" (the conductances) adds up. A divider tells how the voltage (or current) is shared: in proportion to who offers more resistance (or more conductance).

</div>

</Layer>

<Layer kind="formalismo">

<div data-note-id="serie-parallelo-partitori-teoria-1">

**Series.** One-ports carrying the same current: $R_{eq}=\sum R_k$. **Parallel.** One-ports with the same voltage: $G_{eq}=\sum G_k$, i.e. $\dfrac1{R_{eq}}=\sum\dfrac1{R_k}$; for two resistors $R_{eq}=\dfrac{R_1R_2}{R_1+R_2}$.

</div>

<div data-note-id="serie-parallelo-partitori-teoria-2">

**Voltage divider** (series, total voltage $v$): $v_k=v\,\dfrac{R_k}{\sum_j R_j}$. **Current divider** (parallel, total current $i$): $i_k=i\,\dfrac{G_k}{\sum_j G_j}$.

</div>

<div data-note-id="serie-parallelo-partitori-teoria-3">

Condition for the voltage divider: the current is the same in all the resistors, i.e. no downstream load drawing current.

</div>

<details class="proof" data-note-id="serie-parallelo-partitori-dimostrazione-1">
<summary>Proof: Voltage divider</summary>

1. Common current (KCL): $i=v/(R_1+R_2)$.
2. Constitutive relation of $R_2$: $v_2=R_2\,i=v\,\dfrac{R_2}{R_1+R_2}$. $\square$

</details>

<Layer kind="esempio">

<div class="worked" data-note-id="serie-parallelo-partitori-esempio-1">

### Series-parallel network

$R_1=6\,\Omega$ and $R_2=3\,\Omega$ in parallel, in series with $R_3=4\,\Omega$, fed by $18\,\mathrm{V}$. Find the current $i$ in $R_1$.

**Solution.**

1. $R_{12}=6\cdot3/9=2\,\Omega$, $R_{eq}=2+4=6\,\Omega$, $i_{tot}=18/6=3\,\mathrm{A}$.
2. Current divider: $i_1=3\cdot\dfrac{1/6}{1/6+1/3}=3\cdot\dfrac13=1\,\mathrm{A}$.

</div>

</Layer>

<Layer kind="errori">

<div data-note-id="serie-parallelo-partitori-errore-1">

- **Wrong:** Using the voltage divider with a load connected to the middle node without including it.
- **Right:** The load is in parallel with $R_2$: use $R_2\parallel R_L$.
