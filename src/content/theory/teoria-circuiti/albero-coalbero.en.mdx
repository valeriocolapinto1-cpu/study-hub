<Layer kind="intuizione">

<div data-note-id="albero-coalbero-intuizione-1">

A tree is the most economical way to connect all the nodes: no closed path, no redundant branch. Every extra (cotree) branch closes exactly one loop: this is how independent equations are counted without missing or repeating any.

</div>

</Layer>

<Layer kind="formalismo">

<div data-note-id="albero-coalbero-teoria-1">

A **tree** is a connected subgraph containing all the nodes and no loop. The branches not belonging to the tree form the **cotree** (_link_ branches). A tree has $n-1$ branches, the cotree $b-n+1$.

</div>

<div data-note-id="albero-coalbero-teoria-2">

Adding a cotree branch to the tree closes one and only one loop: the **fundamental loop** of that branch (traversed in the direction of the cotree branch). There are $b-n+1$ linearly independent fundamental loops. Removing a tree branch splits the tree into two parts: the branches joining the two parts (the tree branch plus the cotree branches connecting them) form the **fundamental cut set** of that branch. There are $n-1$ of them, independent.

</div>

<div data-note-id="albero-coalbero-teoria-3">

The choice of the tree is not unique: the fundamental loops and cut sets depend on it.

</div>

<details class="proof" data-note-id="albero-coalbero-dimostrazione-1">
<summary>Proof: A tree with $n$ nodes has $n-1$ branches</summary>

1. By induction on $n$. With $n=1$ there are no branches: $0=n-1$.
2. A tree with $n\ge2$ nodes has at least two nodes of degree 1 (leaves): starting from a node, follow a path without loops; you reach a node from which you cannot continue without closing a loop, i.e. a leaf, and the same holds from the other end.
3. Remove a leaf together with its only branch: what remains is a tree with $n-1$ nodes which, by hypothesis, has $n-2$ branches.
4. Hence the original tree has $(n-2)+1=n-1$ branches. $\square$

</details>

<Layer kind="esempio">

<div class="worked" data-note-id="albero-coalbero-esempio-1">

### Fundamental loops and cut sets on 4 nodes

In the graph of the figure (tree: 0-1, 0-2, 0-3) list the fundamental loops and cut sets.

**Solution.**

1. $n=4$, $b=6$: tree with 3 branches, cotree with 3 branches (1-2, 2-3, 1-3).
2. Fundamental loops: (1-2)+(0-1)+(0-2); (2-3)+(0-2)+(0-3); (1-3)+(0-1)+(0-3): 3 loops of 3 branches.
3. Fundamental cut sets: 3, one per tree branch. The cut set of 0-1 separates node 1 from the rest: it contains 0-1, 1-2, 1-3.

</div>

<Layer kind="errori">

<div data-note-id="albero-coalbero-errore-1">

- **Wrong:** Choosing as a "tree" a set of $n-1$ branches that contains a loop (and leaves a node isolated).
- **Right:** $n-1$ branches are a tree only if they connect all the nodes without loops.

</div>
